# Submission checklist

Complete these account and history steps before submitting the assignment:

- [ ] Create a public GitHub repository with `main` as the default branch.
- [ ] Make at least 10 descriptive commits across multiple days. Commit incremental work such as scaffold, input, analysis, UI, logging, CI, and documentation as each milestone is completed.
- [ ] Replace the `HF_SPACE` value in `.github/workflows/deploy-huggingface.yml`.
- [ ] Create an HF write token and save it only as the GitHub Actions secret `HF_TOKEN`.
- [ ] Push to `main` and confirm the verification job and deployment job both pass.
- [ ] Replace the live Space placeholder in `README.md`.
- [ ] Add the failed-run URL, screenshot, failure, fix commit, and successful-run URL to `docs/ci-failure-evidence.md`.
- [ ] Submit the GitHub URL, Space URL, and a 3-5 sentence hardest-problem summary.
